# ปุยปุย ภารกิจพิชิตหอคอยลมหายใจ

เกมเว็บสำหรับ GitHub Pages

## วิธีเผยแพร่
1. แตกไฟล์ ZIP นี้
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์หลักของ repository เดียวกัน
3. ใน GitHub เปิด Settings > Pages แล้วเลือก branch และโฟลเดอร์ `/ (root)`
4. เปิดลิงก์ Pages บน iPad หรือมือถือ

เก็บ `index.html` ภาพ PNG และฉาก SVG ทั้งหมดไว้ด้วยกัน เพื่อให้ตัวละครและฉากของทุกด่านแสดงครบ
