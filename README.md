# ปุยปุย ภารกิจพิชิตหอคอยลมหายใจ

เกมเว็บสำหรับ GitHub Pages

## วิธีเผยแพร่
1. แตกไฟล์ ZIP นี้
2. อัปโหลด `index.html`, `arcade_background_long.png` และ `bird_flight_sprite.png` ไว้ที่โฟลเดอร์หลักของ repository เดียวกัน
3. ใน GitHub เปิด Settings > Pages แล้วเลือก branch และโฟลเดอร์ `/ (root)`
4. เปิดลิงก์ Pages บน iPad หรือมือถือเพื่อทดลอง

เกมใช้ภาพประกอบที่อยู่ข้างไฟล์ `index.html` จึงควรเก็บทั้งสามไฟล์ไว้ด้วยกัน
